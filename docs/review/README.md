# 复盘资料：大白话 + 面试官视角

这个目录是每课的"学习复盘"，区别于 `docs/sNN-notes.md`（偏机制笔记）。每篇分两部分：

- **大白话讲**：用生活化类比把这一课讲清楚，帮自己建立直觉。
- **如果我是面试官**：分层的面试问题 + 参考答案，用来检验和复述。

用法建议：先看大白话建立直觉，再合上文档自己回答面试题，最后对答案补缺口。
