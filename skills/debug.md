# 调试策略

## 排查流程

1. **复现问题**：确认 bug 可以稳定复现
2. **缩小范围**：通过日志/打印定位问题区域
3. **验证假设**：针对最可能的原因进行验证
4. **修复并确认**：修改代码后确认 bug 已修复且无新问题

## 常用技巧

- 用 `echo` 或 `print` 在关键位置输出变量值
- 用 `git diff` 查看最近的改动
- 逐步排除法：注释掉一半代码看问题是否消失
- 检查边界条件：空值、零值、越界、编码

## 常见错误模式

| 类型 | 特征 | 排查方法 |
|---|---|---|
| 路径问题 | 文件找不到 | 检查相对/绝对路径，用 `ls` 确认 |
| 编码问题 | 乱码或解码报错 | 确认文件编码，统一用 UTF-8 |
| 权限问题 | Permission denied | 用 `ls -la` 检查文件权限 |
| 环境差异 | 本地能跑部署不行 | 对比 Python 版本、依赖版本 |
