# Git 工作流

## 提交规范

- 提交信息用中文，格式：`<类型>：<简述>`
- 类型：新增 / 修复 / 重构 / 文档 / 性能
- 每次提交只做一件事，便于回滚和 review

## 常用操作

| 场景 | 命令 |
|---|---|
| 查看状态 | `git status` |
| 查看差异 | `git diff` |
| 查看历史 | `git log --oneline -10` |
| 撤销工作区修改 | `git checkout -- <file>` |
| 暂存当前工作 | `git stash` |
| 恢复暂存 | `git stash pop` |

## 分支策略

- main 分支保持可运行状态
- 新功能在独立分支开发，完成后合并回 main
- 合并前确认代码能正常运行
