# 重构指南

## 重构原则

- 小步修改，每步都可验证
- 一次只重构一件事
- 重构前后行为不变（功能不变）
- 提交前确保代码能正常运行

## 什么时候该重构

- 重复代码出现三次（三次法则）
- 函数超过 20 行
- 嵌套超过 3 层
- 命名需要注释才能理解

## 常见重构手法

| 手法 | 说明 | 示例 |
|---|---|---|
| 提取函数 | 长函数拆成小函数 | 每个函数只做一件事 |
| 重命名 | 让名字表达意图 | `fn1` → `read_config` |
| 消除重复 | DRY 原则 | 多处相同逻辑合并 |
| 简化条件 | 复杂 if-else 简化 | 用字典映射替代多层 if |

## 重构步骤

1. 先确认当前代码能正常运行
2. 做最小的修改
3. 验证修改后仍然正常
4. 提交这一步
5. 重复 2-4
